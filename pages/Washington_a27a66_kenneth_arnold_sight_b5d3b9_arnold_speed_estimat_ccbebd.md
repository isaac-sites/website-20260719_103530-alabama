## Introduction

[Kenneth Arnold]({{ 'kenneth-arnold/' | relative_url }})’s reported speed estimate is one of the most debated aspects of the famous 24 June 1947 sighting near Mount Rainier. His conclusion that the objects were travelling at roughly 1,000–1,700 mph helped transform the case from an unusual aerial observation into a major aviation mystery, because no operational aircraft of the period could match such performance. Yet the calculation was never a direct measurement. It depended on assumptions about where the objects were, how far they travelled between mountain landmarks, and how accurately their transit was timed. As a result, Arnold's estimate remains important not because it proves extraordinary performance, but because it illustrates how difficult it is to derive speed from a single visual observation without independent range or radar data.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://airandspace.si.edu/stories/editorial/1947-year-flying-saucer" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: airandspace.si.edu">[si.edu]</a><span class="citation-popover" role="note"><span class="citation-popover-source">airandspace.si.edu</span><span class="citation-popover-title">1947 year flying saucer</span><span class="citation-popover-snippet">National Air and Space Museum1947: Year of the Flying Saucer &#124; National Air and Space MuseumJune 24, 2022...</span><span class="citation-popover-meta">Published: June 24, 2022</span></span></span>

## How Arnold Timed the Objects Between Cascade Landmarks

Arnold did not have radar, photographic evidence or any instrument capable of measuring the objects' speed. Instead, he used a method familiar to many pilots: timing how long an object appeared to take to cross between known geographical points.

According to his written statement, Arnold watched the formation move southwards from the vicinity of Mount Rainier towards Mount Adams. When the last object passed the southern side of Mount Adams, he checked the sweep second hand on his cockpit clock and concluded that the group had covered the route in approximately 1 minute and 42 seconds. Using an estimated distance of about 50 miles between the relevant mountain positions, he calculated a speed in excess of 1,700 mph, although later retellings often rounded this to around 1,200–1,400 mph.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.bluebook.one/case/62-HQ-83894/serial/0ed73dbf-4f1d-43ba-a3e5-29660c4b75bf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bluebook.one">[bluebook.one]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bluebook.one</span><span class="citation-popover-snippet">FBI Case File 62-HQ-83894 Section 2: Flying Disc Sighting Reports and Investigations, Summer 1947 &#124; BlueBookJuly 9, 1947...</span><span class="citation-popover-meta">Published: July 9, 1947</span></span></span>

The important point is that the timing itself was only one part of the calculation. Even if the 102-second timing were exact, the estimated speed would only be accurate if:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* the objects actually travelled along the route Arnold assumed;
* they were close to the mountain landmarks rather than well in front of or behind them;
* the distance between their actual positions matched the distance used in the calculation.

</div>

None of those conditions could be independently verified.

## Why Small Distance Errors Produce Huge Speed Errors

The weakest part of Arnold's calculation was not necessarily the stopwatch but the estimated distance.

Humans judge the distance of unfamiliar airborne objects poorly, especially against dramatic mountain scenery where there are few reliable visual depth cues. A distant object can appear to skim along a mountain ridge while actually being many miles nearer or farther away.

Arnold himself estimated that the objects were roughly 20–25 miles away. That estimate was based largely on visual judgement rather than measurement. He also inferred their apparent size by comparing them with a distant DC-4 airliner visible elsewhere in the sky, another comparison that depended on assumptions about relative distance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.bluebook.one/case/62-HQ-83894/serial/0ed73dbf-4f1d-43ba-a3e5-29660c4b75bf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bluebook.one">[BlueBook]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bluebook.one</span><span class="citation-popover-snippet">FBI Case File 62-HQ-83894 Section 2: Flying Disc Sighting Reports and Investigations, Summer 1947 &#124; BlueBookJuly 9, 1947...</span><span class="citation-popover-meta">Published: July 9, 1947</span></span></span>

Because speed equals distance divided by time, any substantial error in estimated distance immediately changes the calculated velocity.

For example:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* if the true flight path were close to the assumed 50 miles, the calculated speed remains around 1,700 mph;
* if the actual path were only 25 miles, the speed falls to roughly 850 mph;
* if the objects were much closer still, the calculated speed becomes compatible with much slower aircraft or even other conventional objects.

</div>

The relationship is linear: halve the distance and the estimated speed is halved. Since the distance was never independently established, neither was the speed.

This uncertainty also affects Arnold's estimate that the objects were roughly 45–50 feet across. Apparent size and distance are inseparable in visual observation. If the objects were closer than assumed, they would have been correspondingly smaller; if farther away, larger.

## Did the Mountain Landmarks Fix Their Position?

One reason Arnold believed his estimate was reliable was that he saw the objects pass between prominent Cascade peaks.

However, mountain alignment alone cannot establish an object's precise distance from an observer.

An aircraft, bird or other object many miles closer to Arnold could still appear to cross in front of the same ridge line. Likewise, an object farther beyond the mountains could produce a similar apparent path. Without stereoscopic measurement, radar ranging or simultaneous observations from another location, there is no way to determine which of these possibilities was correct.

Modern discussions of the sighting therefore distinguish between:

* **apparent track**, which Arnold observed directly; and
* **true three-dimensional flight path**, which he had to infer.

Only the first is directly supported by observation.

## Could Conventional Aircraft Match the Estimate?

If Arnold's assumptions were broadly correct, the reported speeds greatly exceeded known operational aircraft performance in mid-1947.

The Bell X-1 would not make the first officially recognised supersonic flight until several months later, and conventional military aircraft of the period were far slower. That mismatch was one reason the report attracted immediate attention from both journalists and military investigators.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.airandspaceforces.com/article/0611ufo/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: airandspaceforces.com">[Air &amp; Space Forces Magazine]</a><span class="citation-popover" role="note"><span class="citation-popover-source">airandspaceforces.com</span><span class="citation-popover-title">Air &amp; Space Forces Magazine USAF and the UFOs &#124; Air &amp; Space Forces Magazine</span><span class="citation-popover-snippet">Air &amp; Space Forces Magazine USAF and the UFOs &#124; Air &amp; Space Forces Magazine</span></span></span>

However, if the distance estimate was substantially wrong, the apparent speed drops accordingly. This means the speed calculation cannot, by itself, eliminate conventional aircraft from consideration.

Military investigators also found no evidence that secret aircraft were operating in the reported area at the relevant time, although the absence of such evidence does not identify what Arnold actually observed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.history.com/articles/kenneth-arnold" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: history.com">[HISTORY]</a><span class="citation-popover" role="note"><span class="citation-popover-source">history.com</span><span class="citation-popover-title">Kenneth Arnold</span><span class="citation-popover-snippet">Kenneth Arnold - UFO, 1947 &amp; Flying Saucer &#124; HISTORY...</span></span></span>

## Birds and Atmospheric Explanations Tested Against the Estimate

Several sceptical explanations have focused on reducing the required speed rather than accepting the original calculation at face value.

One proposal is that Arnold observed large birds, such as pelicans, whose white undersides could produce bright flashes of reflected sunlight while banking. If the birds were much closer than Arnold believed, both their apparent size and calculated speed would have been greatly exaggerated. Critics of this explanation argue that Arnold was an experienced pilot accustomed to judging aircraft and that he watched the objects for several minutes in clear weather.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://airandspace.si.edu/stories/editorial/1947-year-flying-saucer" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: airandspace.si.edu">[National Air and Space Museum]</a><span class="citation-popover" role="note"><span class="citation-popover-source">airandspace.si.edu</span><span class="citation-popover-title">1947 year flying saucer</span><span class="citation-popover-snippet">National Air and Space Museum1947: Year of the Flying Saucer &#124; National Air and Space MuseumJune 24, 2022...</span><span class="citation-popover-meta">Published: June 24, 2022</span></span></span>

Another proposal involves atmospheric effects, such as unusual reflections or mirage-like distortions over mountainous terrain. Arnold explicitly rejected this possibility in his written statement, noting that he viewed the objects both through the aircraft windows and through the open side window. Nevertheless, later Air Force discussions considered atmospheric phenomena among the possible explanations because no physical evidence confirmed the objects' true location.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.bluebook.one/case/62-HQ-83894/serial/0ed73dbf-4f1d-43ba-a3e5-29660c4b75bf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bluebook.one">[BlueBook]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bluebook.one</span><span class="citation-popover-snippet">FBI Case File 62-HQ-83894 Section 2: Flying Disc Sighting Reports and Investigations, Summer 1947 &#124; BlueBookJuly 9, 1947...</span><span class="citation-popover-meta">Published: July 9, 1947</span></span></span>

Neither explanation has achieved universal acceptance, but both illustrate the central issue: if the objects were not where Arnold thought they were, the remarkable speed estimate loses much of its force.

## What the Speed Estimate Still Tells Us

Arnold's calculation should not be dismissed as careless. On the contrary, it shows an observer attempting to use identifiable landmarks, timing and geometry rather than relying solely on impression. His written account demonstrates that he recognised speed as something that could be estimated systematically, not merely guessed.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.bluebook.one/case/62-HQ-83894/serial/0ed73dbf-4f1d-43ba-a3e5-29660c4b75bf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: bluebook.one">[BlueBook]</a><span class="citation-popover" role="note"><span class="citation-popover-source">bluebook.one</span><span class="citation-popover-snippet">FBI Case File 62-HQ-83894 Section 2: Flying Disc Sighting Reports and Investigations, Summer 1947 &#124; BlueBookJuly 9, 1947...</span><span class="citation-popover-meta">Published: July 9, 1947</span></span></span>

At the same time, the calculation highlights the limits of a single eyewitness observation. Without independent confirmation of distance, the reported velocity cannot be treated as a measured fact. Most modern historians of the case therefore regard the extraordinary speed as conditional rather than established: it is extraordinary only if Arnold's assumptions about range and flight path were substantially correct.

Within the history of [Washington]({{ 'why-washington-became-americas-first-ufo/' | relative_url }})'s most famous UFO case, this distinction remains crucial. The reported timing is well documented, but the extraordinary speed depends on geometric assumptions that can no longer be tested, leaving the calculation as one of the strongest reasons the sighting became famous—and one of its most significant evidential weaknesses.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://airandspace.si.edu/stories/editorial/1947-year-flying-saucer" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: airandspace.si.edu">[si.edu]</a><span class="citation-popover" role="note"><span class="citation-popover-source">airandspace.si.edu</span><span class="citation-popover-title">1947 year flying saucer</span><span class="citation-popover-snippet">National Air and Space Museum1947: Year of the Flying Saucer &#124; National Air and Space MuseumJune 24, 2022...</span><span class="citation-popover-meta">Published: June 24, 2022</span></span></span>

    return encodeURIComponent(String(value || '').replace(/\s+/g, ' ').trim()).replace(/%20/g, '+');
  }
  function buildUrl(query, reference, marketId) {
    var cfg = markets[marketId] || markets[defaultMarket];
    if (!cfg) return '#';
    var template = String(cfg.url_template || 'https://www.ebay.com/sch/i.html?_nkw={query}');
    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
</script>
