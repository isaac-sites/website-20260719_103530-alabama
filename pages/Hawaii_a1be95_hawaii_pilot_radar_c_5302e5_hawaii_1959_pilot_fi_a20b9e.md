## Introduction

On 11 July 1959, several airline crews flying over the central Pacific near [Hawaii]({{ 'what-really-happened-in-hawaiis-ufo/' | relative_url }}) reported a striking luminous object that appeared briefly in the night sky. Because the witnesses were experienced commercial aviators and because multiple aircraft reported the event independently, the sighting became one of Hawaii's most frequently cited aviation UFO cases. Yet the same records that made the incident famous also contain the clues that point towards a more ordinary explanation.



<img src="{{ "/assets/images/Hawaii_a1be95_hawaii_pilot_radar_c_5302e5_hawaii_1959_pilot_fi_a20b9e-Illustration-1-dark.svg" | relative_url }}" alt="1959 Sighting illustration 1" data-theme-src-dark="{{ "/assets/images/Hawaii_a1be95_hawaii_pilot_radar_c_5302e5_hawaii_1959_pilot_fi_a20b9e-Illustration-1-dark.svg" | relative_url }}" data-theme-src-light="{{ "/assets/images/Hawaii_a1be95_hawaii_pilot_radar_c_5302e5_hawaii_1959_pilot_fi_a20b9e-Illustration-1-light.svg" | relative_url }}" loading="eager" decoding="sync" fetchpriority="high">

The central question is not whether the crews saw something unusual—they clearly did—but whether they all saw the same controlled object. The surviving Air Force Project Blue Book file suggests that they witnessed a short-lived atmospheric event visible across a large area of sky. Differences between the reports, once presented as evidence of mystery, are now one of the strongest arguments for a bright meteor or fireball that fragmented while crossing the Pacific sky.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://upload.wikimedia.org/wikipedia/commons/3/31/Project_Blue_Book_report_-_1959-07-8407325-NorthPacific-Hawaii-.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: upload.wikimedia.org">[Wikimedia Commons]</a><span class="citation-popover" role="note"><span class="citation-popover-source">upload.wikimedia.org</span><span class="citation-popover-snippet">Wikimedia Commons.,_ - ~January 6, 2015 — SLICK AIRWAYS FLIGHT 719/11. ## What the five aircraft crews reported

The incident occurred during the early hours of 11 July 1959 as aircraft approached or crossed routes east of Hawaii. Project Blue Book records observations from multiple commercial flights, including Pan American, Canadian Pacific and Slick Airways crews. The sightings were brief, generally lasting only a few seconds.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://upload.wikimedia.org/wikipedia/commons/3/31/Project_Blue_Book_report_-_1959-07-8407325-NorthPacific-Hawaii-.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: upload.wikimedia.org">[Wikimedia Commons]</a><span class="citation-popover" role="note"><span class="citation-popover-source">upload.wikimedia.org</span><span class="citation-popover-snippet">Wikimedia Commons.,_ - ~January 6, 2015 — SLICK AIRWAYS FLIGHT 719/11. The most widely publicised account came from a Pan American crew. According to reports later reproduced in UFO literature, the pilots saw a brilliant object accompanied by several smaller lights. The formation appeared to approach rapidly, seemed to alter course sharply, and then vanished. Contemporary newspaper coverage amplified the dramatic aspects of the account, helping to establish the case as a notable UFO report.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://upload.wikimedia.org/wikipedia/commons/3/31/Project_Blue_Book_report_-_1959-07-8407325-NorthPacific-Hawaii-.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: upload.wikimedia.org">[Wikimedia Commons]</a><span class="citation-popover" role="note"><span class="citation-popover-source">upload.wikimedia.org</span><span class="citation-popover-snippet">Wikimedia Commons.,_ - ~January 6, 2015 — SLICK AIRWAYS FLIGHT 719/11. Other crews described the same event very differently. Accounts variously referred to:

* A bright white light.
* An orange or yellow glow.
* A flare-like or tracer-like object.
* A light with apparent companion fragments.
* A brief streak that disappeared quickly.

Not all observers reported multiple lights. Not all described a manoeuvre. Some mentioned colours that others did not see. The duration estimates also varied. These inconsistencies are important because they are found in reports made by trained observers who were looking from different locations and angles.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://upload.wikimedia.org/wikipedia/commons/3/31/Project_Blue_Book_report_-_1959-07-8407325-NorthPacific-Hawaii-.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: upload.wikimedia.org">[Wikimedia Commons]</a><span class="citation-popover" role="note"><span class="citation-popover-source">upload.wikimedia.org</span><span class="citation-popover-snippet">Wikimedia Commons.,_ - ~January 6, 2015 — SLICK AIRWAYS FLIGHT 719/11. ## Why the witness accounts differed

At first glance, differing descriptions can seem to strengthen a UFO claim. If several crews independently reported something unusual, perhaps each observed different aspects of a complex craft. The problem is that the differences in the 1959 reports are not minor details. They concern the very features that would normally identify a structured object.

Observers disagreed about:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* The number of lights present.
* The colour of the phenomenon.
* Whether it had a tail.
* Whether it moved in a straight line or appeared to turn.
* Whether it resembled a single object or several objects travelling together.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://upload.wikimedia.org/wikipedia/commons/3/31/Project_Blue_Book_report_-_1959-07-8407325-NorthPacific-Hawaii-.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: upload.wikimedia.org">[Wikimedia Commons]</a><span class="citation-popover" role="note"><span class="citation-popover-source">upload.wikimedia.org</span><span class="citation-popover-snippet">Wikimedia Commons.,_ - ~January 6, 2015 — SLICK AIRWAYS FLIGHT 719/11. BEEN METEOR· on July 11, 1959, aho over the Pacific [18]. The pilo...</span><span class="citation-popover-meta">Published: January 6, 2015</span></span></span>

</div>

These contradictions fit surprisingly well with the behaviour of a large fireball meteor. A bright meteor can fragment into multiple glowing pieces. Different observers may see different fragments depending on their viewing angle. A break-up can create the impression of formation flying, while perspective effects near the horizon can make a straight trajectory appear curved.

Distance estimation is another major factor. When observers do not know how far away a luminous object is, apparent motion can be misleading. A meteor many kilometres away may seem to race directly towards an aircraft or execute a sudden turn when, in reality, the observer's viewing geometry is changing rapidly. The same effect has appeared repeatedly in aviation reports involving meteors and re-entering space debris.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cia.gov/readingroom/docs/CIA-RDP81R00560R000100040013-4.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cia.gov">[CIA]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cia.gov</span><span class="citation-popover-snippet">FACT SHEET AIR FORCE UFO REPORTThere are still many sightings which are due to the viewing of startling natural objects for the first...</span></span></span>

The brief duration of the Hawaii event also matters. Most reports lasted only seconds. Human observers are generally poor at estimating speed, distance and direction during very short, unexpected events, even when they are highly trained in aviation tasks. The crews were expert pilots, but they were not observing under controlled scientific conditions.

## How well the fireball explanation fits

Project Blue Book ultimately classified the event as most consistent with a fireball meteor. That conclusion was not based on dismissing the witnesses. Rather, investigators compared the reports and noted that the descriptions matched known characteristics of exceptionally bright meteors visible over large regions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://upload.wikimedia.org/wikipedia/commons/3/31/Project_Blue_Book_report_-_1959-07-8407325-NorthPacific-Hawaii-.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: upload.wikimedia.org">[Wikimedia Commons]</a><span class="citation-popover" role="note"><span class="citation-popover-source">upload.wikimedia.org</span><span class="citation-popover-snippet">Wikimedia Commons.,_ - ~January 6, 2015 — SLICK AIRWAYS FLIGHT 719/11. BEEN METEOR· on July 11, 1959, aho over the Pacific [18]. The pilo...</span><span class="citation-popover-meta">Published: January 6, 2015</span></span></span>

Several aspects of the case support that interpretation.

**The sightings were brief.** Fireballs often remain visible for only a few seconds before fading or fragmenting. The reported durations fall comfortably within that range.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://upload.wikimedia.org/wikipedia/commons/3/31/Project_Blue_Book_report_-_1959-07-8407325-NorthPacific-Hawaii-.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: upload.wikimedia.org">[Wikimedia Commons]</a><span class="citation-popover" role="note"><span class="citation-popover-source">upload.wikimedia.org</span><span class="citation-popover-snippet">Wikimedia Commons.,_ - ~January 6, 2015 — SLICK AIRWAYS FLIGHT 719/11. The 1959 sighting survives in UFO literature because it combines several features that attract attention: multiple witnesses, professional pilots, dramatic descriptions and an apparent lack of an immediate explanation. ## What the 1959 sighting tells us about Hawaii's UFO record

Within Hawaii's history of pilot and radar sightings over the central Pacific, the 1959 incident is a useful reminder that credible witnesses do not automatically produce identical observations. In fact, the opposite can occur. When a brief atmospheric event is viewed from many angles, witness testimony may diverge sharply even though everyone is describing the same phenomenon.

For that reason, the case is often more valuable as a lesson in interpretation than as evidence of an unexplained craft. The reports show how easily brightness, distance, fragmentation and perspective can transform a likely fireball into a seemingly extraordinary aerial encounter. More than six decades later, the 1959 sighting remains one of Hawaii's best-known aviation UFO cases precisely because it sits at the boundary between an impressive observation and a plausible natural explanation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://upload.wikimedia.org/wikipedia/commons/3/31/Project_Blue_Book_report_-_1959-07-8407325-NorthPacific-Hawaii-.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: upload.wikimedia.org">[wikimedia.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">upload.wikimedia.org</span><span class="citation-popover-snippet">Wikimedia Commons.,_ - ~January 6, 2015 — SLICK AIRWAYS FLIGHT 719/11.     return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
