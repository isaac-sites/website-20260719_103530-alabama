## Introduction

On 9 October 1951, two aviation-related witnesses reported unusual silver objects within minutes of one another near Terre Haute, [Indiana]({{ 'what-really-happened-in-indianas-ufo/' | relative_url }}). At first glance the reports seemed potentially connected: both involved experienced observers, both described bright metallic-looking objects in daylight, and the sightings occurred only a few minutes apart in the same general region. Yet the case became notable in Project [Blue Book]({{ 'blue-book-a7e130/' | relative_url }}) records not because investigators solved it, but because they could not confidently determine whether the two witnesses had even seen the same thing. The resulting investigation, including an experimental weather-balloon test, illustrates both the strengths and limitations of early Air Force UFO inquiries. Rather than producing a dramatic conclusion, the Terre Haute case became an example of how uncertainty itself could prevent a firm identification.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://upload.wikimedia.org/wikipedia/commons/3/3b/Project_Blue_Book%2C_BBA-PBSR1-300.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: upload.wikimedia.org">[Wikimedia Commons]</a><span class="citation-popover" role="note"><span class="citation-popover-source">upload.wikimedia.org</span><span class="citation-popover-title">Project Blue Book, BBA PBSR1 300</span><span class="citation-popover-snippet">Wikimedia CommonsThe Project Blue Book ArchiveOn 9 October 1951 at 1342 CST, a CAA Chief Aircraft Connaunicator observed a silver object...</span><span class="citation-popover-meta">Published: October 1951</span></span></span>

## Did Two Terre Haute Witnesses See One Object?

The incident began at 1:42 p.m. Central Standard Time at Hulman Municipal Airport in Terre Haute. Roy Messmore, the Civil Aeronautics Administration (CAA) chief aircraft communicator, reported seeing a round silver object pass directly overhead. According to the official summary, the object crossed the sky rapidly and reached the horizon in roughly fifteen seconds. Messmore was an aviation professional accustomed to observing aircraft and weather conditions, which gave his report greater weight than an ordinary casual observation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://upload.wikimedia.org/wikipedia/commons/3/3b/Project_Blue_Book%2C_BBA-PBSR1-300.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: upload.wikimedia.org">[wikimedia.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">upload.wikimedia.org</span><span class="citation-popover-title">Project Blue Book, BBA PBSR1 300</span><span class="citation-popover-snippet">Wikimedia CommonsThe Project Blue Book ArchiveOn 9 October 1951 at 1342 CST, a CAA Chief Aircraft Connaunicator observed a silver object...</span><span class="citation-popover-meta">Published: October 1951</span></span></span>

Only minutes later, another aviation witness reported a seemingly similar object. A pilot flying between Indiana and Illinois radioed that he had seen a large silvery object near Paris, Illinois, northwest of Terre Haute. In later descriptions of the case, the pilot said the object resembled a flattened orange and appeared nearly motionless relative to his aircraft before he turned to obtain a better view.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.gutenberg.org/cache/epub/17346/pg17346-images.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: gutenberg.org">[Project Gutenberg]</a><span class="citation-popover" role="note"><span class="citation-popover-source">gutenberg.org</span><span class="citation-popover-title">Project Gutenberg The Report on Unidentified Flying Objects</span><span class="citation-popover-snippet">Project Blue Book published a classified monthly report on UFO activity.... Within the framework of early Blue Book investigations, this raised the possibility that both men had observed the same target from different positions. If true, the paired sightings might have provided a stronger basis for estimating the object's location, altitude and movement than either report could provide on its own.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://sacred-texts.com/ufo/rufo/rufo11.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sacred-texts.com">[Internet Sacred Text Archive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sacred-texts.com</span><span class="citation-popover-snippet">Internet Sacred Text ArchiveThe Report on Unidentified Flying Objects: Chapter Nine......The report from Terre Haute said that on Octob...</span></span></span>

## The Airport Communicator and Pilot Reports

Although the reports appeared similar, important differences emerged when investigators examined them more closely.

Messmore's observation suggested a fast-moving object travelling across the sky. His description emphasised rapid passage overhead and disappearance toward the horizon. The pilot's account, by contrast, described an object that initially appeared almost stationary before he manoeuvred his aircraft to look at it more carefully. The shapes described were not identical either: one report referred to a round silver object, while the pilot compared what he saw to a flattened orange.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://upload.wikimedia.org/wikipedia/commons/3/3b/Project_Blue_Book%2C_BBA-PBSR1-300.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: upload.wikimedia.org">[wikimedia.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">upload.wikimedia.org</span><span class="citation-popover-title">Project Blue Book, BBA PBSR1 300</span><span class="citation-popover-snippet">Wikimedia CommonsThe Project Blue Book ArchiveOn 9 October 1951 at 1342 CST, a CAA Chief Aircraft Connaunicator observed a silver object...</span><span class="citation-popover-meta">Published: October 1951</span></span></span>

These differences did not necessarily mean the reports were unrelated. Perspective effects can make the same object appear very different to observers at separate locations. A distant object moving toward or away from one witness may appear nearly stationary, while another observer sees obvious motion across the sky. Investigators therefore had to determine whether geometry, distance and viewing angle could reconcile the two descriptions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://sacred-texts.com/ufo/rufo/rufo11.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sacred-texts.com">[Internet Sacred Text Archive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sacred-texts.com</span><span class="citation-popover-snippet">Internet Sacred Text ArchiveThe Report on Unidentified Flying Objects: Chapter Nine......The report from Terre Haute said that on Octob...</span></span></span>

That task proved difficult because the available observations contained too few precise measurements. Neither witness could provide enough information to establish the object's altitude, exact distance or track with confidence. Without those figures, connecting the reports became largely a matter of inference rather than calculation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://sacred-texts.com/ufo/rufo/rufo11.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sacred-texts.com">[Internet Sacred Text Archive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sacred-texts.com</span><span class="citation-popover-snippet">Internet Sacred Text ArchiveThe Report on Unidentified Flying Objects: Chapter Nine......The report from Terre Haute said that on Octob...</span></span></span>

## Why Investigators Tested a Weather-Balloon Explanation

One of the most interesting aspects of the Terre Haute case was the decision to test a weather-balloon hypothesis rather than simply assume one.

Investigators recognised that bright metallic weather balloons frequently generated UFO reports during the late 1940s and early 1950s. Sunlit balloons could appear as brilliant silver objects, sometimes seeming motionless at high altitude and at other times appearing to move rapidly because of changing observer position and atmospheric conditions. Because both Terre Haute reports involved silver objects seen in daylight, a balloon was an obvious candidate explanation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://sacred-texts.com/ufo/rufo/rufo11.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sacred-texts.com">[Internet Sacred Text Archive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sacred-texts.com</span><span class="citation-popover-snippet">Internet Sacred Text ArchiveThe Report on Unidentified Flying Objects: Chapter Nine......The report from Terre Haute said that on Octob...</span></span></span>

Instead of relying solely on paperwork, investigators reportedly conducted a practical comparison by launching a weather balloon under similar conditions. The purpose was to determine whether observers might perceive a balloon in a way that matched the descriptions given by the airport communicator and the pilot. Such field tests reflected the more technical approach that Air Force investigators were beginning to adopt in 1951, when Blue Book sought greater emphasis on observational data and verification.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://sacred-texts.com/ufo/rufo/rufo11.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sacred-texts.com">[Internet Sacred Text Archive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sacred-texts.com</span><span class="citation-popover-snippet">Internet Sacred Text ArchiveThe Report on Unidentified Flying Objects: Chapter Nine......The report from Terre Haute said that on Octob...</span></span></span>

The balloon experiment produced mixed results. It demonstrated that a weather balloon could resemble a bright silver object in the daytime sky. However, it did not conclusively reproduce all aspects of the two reports. The test therefore failed to provide the clear answer investigators hoped for. Rather than proving the sightings were balloons, it merely showed that a balloon explanation remained plausible.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://sacred-texts.com/ufo/rufo/rufo11.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sacred-texts.com">[Internet Sacred Text Archive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sacred-texts.com</span><span class="citation-popover-snippet">Internet Sacred Text ArchiveThe Report on Unidentified Flying Objects: Chapter Nine......The report from Terre Haute said that on Octob...</span></span></span>

## Why the Two Sightings Could Not Be Reliably Connected

The central problem was geometry.

To establish that both witnesses had seen the same object, investigators needed to reconstruct where the object would have been at specific moments and whether the reported directions matched. The available information was too incomplete to do this with confidence.         .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
