## Introduction

One of the strongest claims associated with [Missouri]({{ 'what-really-happened-in-missouris-ufo/' | relative_url }})’s 1973 Piedmont sightings was that some lights appeared to move at extraordinary speeds, change direction abruptly, or cover large distances in very short periods. Yet those conclusions depended on a measurement that [Project Identification]({{ 'project-identification/' | relative_url }}) often struggled to obtain: reliable distance.



<img src="{{ "/assets/images/Missouri_d961c4_project_identificati_0b604a_piedmont_distance_tr_de6e21-Illustration-1-dark.svg" | relative_url }}" alt="Distance Problem illustration 1" data-theme-src-dark="{{ "/assets/images/Missouri_d961c4_project_identificati_0b604a_piedmont_distance_tr_de6e21-Illustration-1-dark.svg" | relative_url }}" data-theme-src-light="{{ "/assets/images/Missouri_d961c4_project_identificati_0b604a_piedmont_distance_tr_de6e21-Illustration-1-light.svg" | relative_url }}" loading="eager" decoding="sync" fetchpriority="high">

Harley Rutledge and his colleagues understood that apparent motion alone proves very little. A light close to an observer can seem to race across the sky, while a distant object may appear nearly stationary. To determine true speed, size or altitude, investigators first needed to know how far away the object was. Their preferred solution was triangulation—observing the same target from different locations and comparing viewing angles. In practice, however, Piedmont’s most puzzling lights rarely cooperated with the requirements of accurate triangulation. As a result, some of the project’s boldest performance estimates remained dependent on uncertain range calculations rather than firmly established measurements.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Harley_Rutledge" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Harley Rutledge</span><span class="citation-popover-snippet">Harley Rutledge</span></span></span>

## How Triangulation Was Meant to Establish Range

Triangulation is a straightforward geometric method. If two observers at known locations simultaneously measure the direction to the same object, the intersecting lines of sight can be used to calculate its position and distance. The method has long been used in surveying, navigation and astronomy because, in principle, knowing a baseline and two angles allows the remaining dimensions of a triangle to be calculated.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://thonyc.wordpress.com/2012/05/25/mapping-the-history-of-triangulation/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: thonyc.wordpress.com">[The Renaissance Mathematicus]</a><span class="citation-popover" role="note"><span class="citation-popover-source">thonyc.wordpress.com</span><span class="citation-popover-snippet">The Renaissance MathematicusMapping the history of triangulationMay 25, 2012 — 25 May 2012 — This principle can be employed to measure ov...</span><span class="citation-popover-meta">Published: May 25, 2012</span></span></span>

For Project Identification, the idea was attractive. Multiple observing stations around the Piedmont area could watch the same light, record its angular position against the sky and compare notes. If the measurements matched, investigators could estimate the object's distance and then derive its altitude, speed and physical size. Rutledge described the project as an attempt to obtain exactly these kinds of quantitative measurements rather than relying solely on witness impressions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Harley_Rutledge" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Harley Rutledge</span><span class="citation-popover-snippet">Harley Rutledge</span></span></span>

The challenge was that triangulation only works when observers are unquestionably tracking the same object at the same moment and measuring it with sufficient precision.

## Why Timing, Angles and Station Matching Often Failed

The Piedmont phenomenon did not resemble a laboratory target. Reports frequently involved isolated lights seen at night, sometimes appearing suddenly, changing brightness, vanishing, or moving against a largely featureless background. These conditions created several problems.

### Were Both Stations Looking at the Same Light?

The most basic difficulty was identification. Multiple lights could be visible in different parts of the sky at once. Even when observers communicated by radio, there was no guarantee that Station A and Station B were measuring the identical target.

A small mismatch could destroy the calculation. If one observer tracked one light while another followed a different light that merely appeared nearby in the sky, the resulting geometry would be meaningless. This problem becomes especially severe at night when distant lights lack obvious structural details.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Harley_Rutledge" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Harley Rutledge</span><span class="citation-popover-snippet">Harley Rutledge</span></span></span>

### Simultaneous Measurements Were Hard to Obtain

Triangulation depends on measurements taken at essentially the same time. Many Piedmont observations involved objects that appeared briefly or changed position before instruments could be aligned.

Even a modest timing error could create a large range error if the object was moving. A light measured by one station and then remeasured seconds later by another might no longer occupy the same position in space. Field investigators therefore faced a practical problem: the very sightings they most wanted to analyse were often the least stable observational targets.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://archive.org/details/projectidentific0000rutl" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archive.org">[Internet Archive]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archive.org</span><span class="citation-popover-snippet">Internet ArchiveProject Identification: the first scientific field study of UFO...8 Sept 2023 — Project Identification: the first scie...</span></span></span>

### Small Angular Errors Produced Large Distance Errors

Night-time angular measurements are difficult. A difference of only a fraction of a degree can dramatically alter a distance estimate, especially when the object is far away.

This is a general limitation of triangulation. When viewing lines are nearly parallel, tiny uncertainties in angle measurement expand into very large uncertainties in calculated range. In the Piedmont case, observers were often dealing with small points of light rather than large, sharply defined objects, making precise angle determination difficult.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://thonyc.wordpress.com/2012/05/25/mapping-the-history-of-triangulation/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: thonyc.wordpress.com">[The Renaissance Mathematicus]</a><span class="citation-popover" role="note"><span class="citation-popover-source">thonyc.wordpress.com</span><span class="citation-popover-snippet">The Renaissance MathematicusMapping the history of triangulationMay 25, 2012 — 25 May 2012 — This principle can be employed to measure ov...</span><span class="citation-popover-meta">Published: May 25, 2012</span></span></span>

### The Baseline Was Not Always Ideal

The distance between observing stations—the baseline—also affects accuracy. If the baseline is too short relative to the target's distance, the parallax effect becomes very small and the calculation becomes highly sensitive to measurement errors.

Modern scientific sky-monitoring projects emphasise carefully designed camera networks and automated timing systems partly because obtaining accurate range estimates for distant aerial objects is so demanding. ## How Uncertain Distance Distorted Speed, Size and Altitude Claims

The most important consequence of uncertain range was that every other physical estimate became uncertain as well.

Consider a light crossing a given angle of sky. If the object is assumed to be one mile away, its actual speed may be modest. If it is assumed to be ten miles away, the same apparent motion implies a much higher velocity. Without a secure distance measurement, apparent speed can be converted into radically different physical speeds.

The same problem affects size. A small nearby light and a large distant light can appear identical to an observer. Altitude estimates suffer from the same ambiguity. A single error in distance propagates through every subsequent calculation.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://arxiv.org/abs/2412.12142" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: arxiv.org">[arXiv]</a><span class="citation-popover" role="note"><span class="citation-popover-source">arxiv.org</span><span class="citation-popover-snippet">A New Method to Derive an Empirical Lower Limit on the Mass Density of a UFODecember 9, 2024...</span><span class="citation-popover-meta">Published: December 9, 2024</span></span></span>

This matters because some of the most dramatic interpretations of the Piedmont sightings relied on derived quantities rather than directly measured ones. Claims that a target moved at extraordinary speed, reached unusual altitudes or possessed a large physical size depended on first establishing where it actually was. When the distance estimate became uncertain, the confidence that could be placed in those secondary calculations dropped as well.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Harley_Rutledge" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Harley Rutledge</span><span class="citation-popover-snippet">Harley Rutledge</span></span></span>

## What the Distance Problem Means for Project Identification


<div class="content-callout content-callout--key content-callout--takeaway" markdown="1">

The failure to obtain consistently reliable range measurements does not mean that observers saw nothing unusual. Project Identification remains noteworthy because trained investigators spent years watching the skies over south-eastern Missouri, identified many conventional objects and attempted more rigorous measurements than most UFO investigations of the era.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Harley_Rutledge" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Harley Rutledge</span><span class="citation-popover-snippet">Harley Rutledge</span></span></span>

</div>

However, the distance problem helps explain why the project never produced decisive proof of extraordinary craft. The key question was not simply whether unusual lights were seen. It was whether investigators could determine where those lights were in three-dimensional space. In many of the most intriguing cases, that step remained unresolved.

As a result, the Piedmont observations often demonstrated the limits of field investigation as much as its possibilities. The project showed that observing unknown lights is relatively easy; proving their true distance, and therefore their true speed, size and altitude, is far harder. That gap between appearance and measurement remains one of the central reasons why the most striking Piedmont claims continue to be debated rather than settled.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://en.wikipedia.org/wiki/Harley_Rutledge" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: Wikipedia">[Wikipedia]</a><span class="citation-popover" role="note"><span class="citation-popover-source">Wikipedia</span><span class="citation-popover-title">Harley Rutledge</span><span class="citation-popover-snippet">Harley Rutledge</span></span></span>

    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
